## 🍍 My Exotic Fruits Store

Интерактивный одностраничный интернет-магазин экзотических фруктов, созданный с применением **JavaScript**.

Реализованы: 
- фильтрация товаров по названию и акционной цене;
- сортировка (по алфавиту, по рейтингу, возрастанию/убыванию цены);
- добавление и удаление товаров из корзины;
- подсчёт итоговой суммы покупок в корзине.

🔗 [Смотреть проект в браузере](https://julia8978.github.io/my-exotic-fruits-store/)
